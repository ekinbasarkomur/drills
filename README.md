# Drills

Drills to keep my software skills — and my sanity — intact through the AI revolution.

Algorithm problems solved by hand, one file per problem per language, each holding the
solution and the tests that prove it. Rust, C++, Python, pandas, SQL.

```
make 155          run problem 155 in every language it has
make rust-155     ... in one language (also cpp-, py-, pandas-, sql-)
make new 155      scaffold a problem from its LeetCode id
make status       what is solved
```
