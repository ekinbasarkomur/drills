# Algorithms

LeetCode / NeetCode 150 problems, each solved in Rust, Python and C++.

The point of doing the same problem three times is not the problem — it is
watching the same idea come out differently in three type systems.

| | Everything | One problem | New problem |
| --- | --- | --- | --- |
| [`rust/`](rust/) | `cargo test` | `cargo test --bin two_sum` | `cp template.rs src/bin/<name>.rs` |
| [`python/`](python/) | `uv run pytest` | `uv run pytest -k two_sum` | `cp template.py solutions/<name>.py` |
| [`cpp/`](cpp/) | `make` | `make two_sum` | `cp template.cpp solutions/<name>.cpp` |

The index of every problem, with source links and which languages are done,
is in the [repository README](../README.md#index).
